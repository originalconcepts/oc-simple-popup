# OC Popup (פופ אפ פשוט)

תוסף וורדפרס לניהול פופ אפים — פותח עבור Original Concepts.

## יכולות
- כותרת, תיאור (עורך ויזואלי), תמונה (כולל מצב "תמונה על כל הפופ אפ") או מוצרי ווקומרס (חיפוש ובחירה)
- כפתור הנעה לפעולה: טקסט, קישור (ללא קישור = סוגר את הפופ אפ), צבעים + רול אובר, פינות, גודל טקסט
- דיסקליימר תחתון עם גודל וצבע פונט
- תצוגה: כל העמודים (עם החרגות) / רק עמוד הבית / עמודים ספציפיים — בחירה בחיפוש, לא לפי ID
- מיקוד מכשיר: דסקטופ / מובייל / שניהם
- קוקי הצגה חוזרת (ברירת מחדל: יום אחד), בדיקה בצד לקוח — תואם קאש
- כיבוי אוטומטי בתאריך ושעה (לפי שעון האתר), נאכף גם בצד לקוח כדי לעבוד עם קאש
- מסך עריכה מפוצל עם תצוגה מקדימה חיה + טאבים הגדרות/עיצוב
- טוגל פעיל/לא פעיל בעורך ובטבלה + עמודות מכשיר וסטטיסטיקה (צפיות/קליקים/סגירות)
- תפריט "OC Pluginz" משותף לכל תוספי OC באתר (`oc-pluginz/`): הכניסה "פופ אפים" תחתיו, ורצועת טאבים (פופ אפים | חשבון OC Pluginz) מעל המסכים
- רישיון OC Pluginz (my.ocpluginz.com, מוצר `oc-popup`): מסך "חשבון OC Pluginz" בטאב לצד פופ אפים
- עדכונים: מה-hub כשיש רישיון מחובר, ומהריפו הזה (GitHub updater מובנה) כשאין

## התקנה
העתקת התיקייה `simple-popup` אל `wp-content/plugins/` והפעלה ממסך התוספים.

## רישיון OC Pluginz
- מוצר `oc-popup` ב-my.ocpluginz.com (מסלולים חודשי / שנתי / לכל החיים). מפתח `ocpz_…` מחובר במסך "OC Pluginz → פופ אפים → חשבון OC Pluginz", או קבוע ב-wp-config.php: `define( 'OSP_LICENSE_KEY', 'ocpz_…' );`
- הרישיון מפעיל את הפופ אפים באתר (כמו בשקוף), רושם את האתר ב-hub ומביא עדכונים. רישיון מושהה, חיוב שנכשל, מנוי שהסתיים אחרי ימי החסד או מפתח שה-hub דחה: הפופ אפים מפסיקים להופיע באתר בבדיקה הבאה (כל שעה, או בפתיחת מסך החשבון). שום דבר לא נמחק, והם חוזרים כשהרישיון מתחדש.
- אתר שהיו בו פופ אפים לפני 1.9.0 (הלקוחות שלנו שמתעדכנים מ-GitHub) מסומן פעם אחת כאתר ותיק (`osp_hub_legacy`) וממשיך לעבוד בלי מפתח, עם עדכונים מהריפו הזה. התקנה חדשה בלי מפתח: אפשר לבנות פופ אפים, אבל הם לא מוצגים באתר. `define( 'OC_PLUGINZ_AGENCY', true );` = בלי רישיון, בלי פניות ל-hub, פופ אפים תמיד פעילים.
- הודעות מ-OC Pluginz: מה שה-hub עונה תחת `notices` לצד הרישיון (תוסף חדש, גרסה חשובה, הודעת שירות) נשמר עם הרישיון ומוצג כהודעת מנהל בכל מסכי הניהול עד שסוגרים אותה (ה-X). הסגירה נשמרת ב-user meta המשותף לכל תוספי OC (`ocpz_dismissed_notices`), כך שהודעה לכל המוצרים מופיעה פעם אחת גם כשיש כמה תוספי OC באתר. במצב סוכנות ובאתר ותיק בלי מפתח אין הודעות.
- הקוד: `includes/hub/` (`OSP_Hub`, `OSP_Notices`, `OSP_Hub_Updater`, `OSP_Hub_Admin`). התפריט המשותף: `oc-pluginz/` (עותק של הספרייה מ-ocpluginz-hub, `lib/oc-pluginz/`; לא עורכים אותו בתוסף).

## שחרור גרסה
1. מעדכנים את `Version:` בכותרת של `simple-popup.php` ואת `OSP_VERSION` (ה-CI בודק שהם זהים)
2. branch + PR, ה-CI (php -l על 7.4–8.3) ירוק, מיזוג ל-`main`
3. אתרים בלי רישיון: תוך עד 6 שעות (או מיד דרך "עדכונים" → "בדוק שוב") יציעו את העדכון
4. אתרים עם רישיון: בונים את החבילה (`bash bin/build-zip.sh`, תיקייה עליונה `simple-popup/`) ומעלים אותה ל-hub בתור `oc-popup.zip`
